# Security Policy

## Supported Versions

The project provides security updates only for actively maintained and stable release lines.

| Version | Supported |
|--------|-----------|
| 5.1.x  | ✔ |
| 4.0.x  | ✔ |
| 5.0.x  | ✘ |
| <4.0   | ✘ |

Older versions are no longer supported and do not receive security patches.

---

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly through a private channel.

Your report should include:
- A clear description of the issue  
- Steps to reproduce  
- Impact assessment (if known)  
- Affected version(s)

After submitting a report, you can expect:
- An acknowledgement within a reasonable timeframe  
- Periodic updates on the assessment status  
- Notification on whether the issue is accepted or declined  
- Coordinated disclosure if the vulnerability is confirmed

We appreciate responsible reporting and aim to maintain a transparent and predictable process for handling security issues.
